## 当前能做什么

- 通过已配置的搜索API检索，整理来源、去重，使用HTTP抓取网页正文。
- 使用DeepSeek整理要点、生成引用综述和对比表，导出Markdown/CSV/JSON。
- 提供快速/多轮深度研究界面、任务状态与日志、提示词管理。
- 提供Pixabay/Pexels API素材检索与受限目录下载；需对应服务配置。

以上是代码实现范围；**真实外网API、HTTP网站兼容性、素材下载和AI研究全链路仍待验证**。当前回归验证不代表真实服务承诺。Tavily所谓“免密”模式尚未获真实服务验证，不保证可用。

### 已禁用的功能

为避免未隔离浏览器执行恶意网页的风险，所有Playwright浏览器网络硬性关闭：
- 浏览器搜索、执行JavaScript后的网页抓取；
- Mixkit、Coverr素材检索；
- HTTP失败时的浏览器兜底。

这是主动的功能降级，不是完整无头浏览器发行版。不能靠设置开关恢复；需要独立网络出口隔离和进一步安全验证。当前版本无需安装Chrome或下载浏览器内核。依赖中仍保留playwright-core以避免不必要的依赖改动，但不运行浏览器。

## 安装和启动

需要 **Node.js >=22** 与npm；受当前jsdom锁定版本限制，实际支持 **22.22.2+（22.x）、24.15.0+（24.x）或26+**，推荐Node24 LTS。Windows/macOS/Linux命令行均可使用；当前只在Linux Node24做过本地验证，未验证其他平台端到端兼容。首次安装依赖需要网络。

```sh
npm ci --ignore-scripts
npm start
```

打开 `http://127.0.0.1:8787`。监听固定为回环地址，勿通过公网代理或隧道暴露。首次打开首页会建立HttpOnly、SameSite=Strict会话；重启后需要重新打开首页。

专用工作根默认为当前用户目录下 `xunyuan-work`，目录选择器只允许此根内访问。可在启动进程的环境变量 `XUNYUAN_WORK_ROOT` 中指定独立目录；不应指向其他项目、个人资料目录或磁盘根。禁止符号链接、越界和编码穿越。CLI的 `--out` 也须写入该根。应用私有配置和任务记录仍保存在应用目录内，请勿与发布源码一同再打包。

### 配置

推荐在本机进程环境中设置 `DEEPSEEK_API_KEY`，其他服务变量见 `.env.example`；也可复制为私有 `.env` 填入，或通过网页设置。**不要把真实密钥粘入终端日志、截图、issue或仓库。** 网页“保存密钥”会写本地 `.env`；该文件已被gitignore排除，但仍需人工检查。

`config.example.json` 不含密钥，可复制为私有 `config.json` 按需调整。监听和浏览器限制由代码强制，不能通过配置改成公网或启用浏览器。DeepSeek的LLM认证目标仅允许官方 `https://api.deepseek.com`。SearXNG仅可使用符合公网HTTP限制的实例，私网实例被拒绝。

## CLI与测试

```sh
node src/cli.js run "研究主题" --providers deepseek --fetch 4 --table
node src/cli.js providers
npm test
```

`npm test` 使用临时数据与假密钥/DNS mock，不调用外部服务。30项隔离测试通过；另有16项本机HTTP权限检查通过，详见 `tests/SECURITY-TEST-RESULTS.md`。`doctor` 原有浏览器检查在本版本会报告禁用，不能作为必过验收项。
